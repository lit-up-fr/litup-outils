📖 Légende
CHARGER (menu ☁️ Charger)
☁️ Dernière sauvegarde — Charger tout depuis le Google Sheet (remplace vos données)
🔀 Fusionner avec le Sheet — Récupérer le travail de l'autre en gardant le vôtre
☁️ NDF — Charger les NDF depuis le Google Sheet
☁️ Dépenses — Charger les dépenses depuis le Google Sheet
🔄 Règles — Appliquer les règles auto aux lignes non classées
IMPORT
📥 Banque — Importer le relevé bancaire (.xlsx Crédit Mutuel)
📎 Justif. — Importer des justificatifs avec OCR et rapprochement auto
📂 JSON — Charger un backup JSON
RAPPROCHEMENT
🔗 NDF — Rapprochement banque ↔ virements NDF
🔗 Dépenses — Rapprochement banque ↔ dépenses (carte, virements, prélèvements)
SAUVEGARDER / EXPORT
☁️ Sauvegarder — Tout sauvegarder vers Google Sheet (partagé)
📤 CSV / FEC / ZIP — Exports pour l'expert-comptable
💾 JSON — Sauvegarder en fichier JSON (backup local)
💡 Travail à deux : Après vos modifications, cliquez ☁️ Sauvegarder. Quand l'autre personne enregistre, un bandeau 🔀 apparaît en haut : cliquez-le pour fusionner. Ce qui ne se recouvre pas est additionné automatiquement, et l'outil ne vous interroge que sur ce que vous avez modifié tous les deux différemment. Rien n'est écrit sans votre validation, et tout est annulable avec ↩️.
☁️ Dernière sauvegarde reste utile pour repartir de zéro : elle remplace vos données.
Code couleur : 🟠 Orange = justificatif manquant · 🟡 Jaune = pas encore classé · 🟢 Vert = classé et nommé · Champs orange = à compléter
Workflow : ① 📥 Banque → ② 🔄 Règles → ③ ☁️ NDF + Dépenses → ④ 🔗 Rapprocher → ⑤ ✂️ Éclater NDF → ⑥ Compléter → ⑦ ☁️ Sauvegarder → ⑧ 📤 FEC
💡 Justificatifs : Glissez-déposez un fichier sur la cellule 📎+ d'une ligne pour l'attacher. Cliquez ✕ pour supprimer un justificatif (aussi du Drive).
